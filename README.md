⚡ AHK Port — автоматизация для GTA 5 RP ⚡

AHK Port — программа для GTA 5 RP, предназначенная для автоматизации игровых действий и упрощения игрового процесса.

🚀 Как включить скрипт?

1️⃣ Запустите программу Port.exe.
2️⃣ Нажмите кнопку «Включить» в программе.
3️⃣ Для активации скрипта нажмите F5.

✅ После этого скрипт будет активирован и готов к использованию.

⏹️ Как выключить скрипт?

Чтобы отключить работу скрипта, выполните следующие действия в указанном порядке:

1️⃣ Нажмите Shift.
2️⃣ Нажмите W.
3️⃣ Нажмите F7.

Скрипт будет выключен.

❌ Как полностью закрыть программу?

Чтобы полностью завершить работу AHK Port, просто выключите программу.
